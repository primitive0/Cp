# Язык программирования C' (/Си-штрих/)

C' — императивный язык программирования со статической типизацией,
C-подобным синтаксисом и ручным управлением памятью.

```c3
fn I32 main() {
    println("Hello, world!");
    return 0;
}
```

## Сборка и тестирование проекта

Проект должен собираться на Linux. Windows не поддерживается. Для сборки проекта требуются:

1. Компилятор C и C++ с поддержкой стандарта C++23 (подходят Clang и GCC)
2. CMake версии ≥3.28
3. LLVM 22, вместе с утилитами lit и FileCheck [^1]
4. Пакетный менеджер Conan 2

```sh
make setup BUILD_TYPE=<тип сборки, Debug или Release>

make build
```

Для запуска всех тестов проекта используйте:

```sh
make test
```

#### Автоматическое обновление эталонов FileTest тестов

Иногда, после внесения изменений в код, нужно пересоздать эталонные файлы FileTest тестов.

```sh
make update-filetests
```
