# Язык программирования C' (/Си-штрих/)

C' — императивный язык программирования со статической типизацией,
C-подобным синтаксисом, ручным управлением памятью, поддержкой модулей
и совместимостью с другими языками через механизм межъязыкового
взаимодействия (FFI).

```c3
fn Unit main() {
    log.println("Hello, world!")
}
```

## Технологии

1. **C++26**
2. **LLVM**
3. **Catch2**
4. **CMake, Conan**
5. **Lit и FileCheck**
6. **org-mode**
