## Код

Добавлены кастомные макросы для контрактов: `CPRIME_ASSERT()`, `CPRIME_DEBUG_ASSERT()` и прочие.

Рефакторинг лексера: классы `Lexer` и `TextScanner` объединены для удобства работы с состоянием курсоров.

Произведён рефакторинг AST: улучшена инкапсуляция, для оптимизации аллокации узлов на куче используется арена на основе `std::pmr::monotonic_buffer_resource`. AST visitor переработан так, чтобы поддерживать возвращаемые значения произвольного типа T из методов visit().

Парсер переписан для работы с новым AST.

Модуль кодогенерации также претерпел изменения: этап понижения AST в LLVM IR вынесен в отдельный файл.

Реализована поддержка целочисленных арифметических выражений.

# 2_compilation_pipeline

## Код

Реализованы следующие этапы компиляции:

1. Лексический анализ.
2. Синтаксический анализ.
3. Кодогенерация c помощью LLVM.

Семантический анализ пока что отсутствует.

Компилятор умеет диагностировать ошибки лексики во всём файле, а также до одной ошибки в отдельной функции.

```
$ cat example.cpr
fn I32 foo() {
    println("unclosed...
}

fn I32 bar() {
    return 1234
}

$ cpc example.cpr
example.cpr:2:13: error: unclosed string literal
example.cpr:7:1: error: expected ';', but found '}'

$
```

## Тестирование

Лексер покрыт unit-тестами. Используется LLVM Lit для тестирования программ, генерируемых компилятором.

Тесты синтаксического анализа отсутствуют. Планируется добавить их в следующей итерации.
