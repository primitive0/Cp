## Программа на языке C'

Каждый файл `.cpr` образует _единицу трансляции_. Каждая единица трансляции образует _программу_. В случае успешной компиляции программы образуется один исполняемый файл.

### Выполнение программы

Эта спецификация определяет правила, по которым можно выполнить программу на языке C' шаг за шагом. Получившиеся после компиляции исполняемые файлы не обязаны в точности повторять эти шаги. Разве, получившиеся после компиляции исполняемые файлы должны воспроизводить _наблюдаемое поведение_, которое получается при выполнении программы шаг за шагом по правилам, описанным здесь.

Наблюдаемое поведение двух выполнений считается одинаковым, если для любого ввода:

1. Нижеперечисленные операции выполняются в одинаковом порядке и с одинаковым результатом:
   1. Чтение из стандартного потока ввода.
   2. Вывод в стандартный поток вывода.
2. Exit-code в выполнениях одинаковый.

Эта спецификация _никак не ограничивает_ выполнение, если в нём есть неопределённое поведение.

### Точка входа

Выполнение программы начинается с выполнения функции `main()`. Выполнение заканчивается при выходе из функции `main()`.

Например, данная программа выводит в stdout строку `Hello, world!` и завершается с кодом `0`.

```c3
fn I32 main() {
    println("Hello, world!");
    return 0;
}
```

## Функции

Каждая единица трансляции состоит из нескольких функций. Имена всех функций различны. Перегрузка функции по аргументам не допускается.

В каждой единице трансляции должна быть функция `main()`, иначе программа некорректна.

### Объявление функции

```c3
fn RetType function(P1 param_1, P2 param_2, ..., Pn param_n) { ... }
```

Чтобы объявить функцию, нужно указать:

- Имя функции
- Возвращаемый тип
- Параметры функции
- Тело функции

Имена параметров функции должны быть различны, иначе программа некорректна.

### Возвращаемое значение функции

Выполнение функции завершается, если:

1. Выполнение тела функции завершается
2. Выполняется инструкция [return](#???)

Если выполняется инструкция `return`, то возвращаемым значением функции считается возвращаемое значение `return`.

Если возвращаемый тип функции `Unit` и тело функции завершает выполнение, то возвращаемым значением функции считается unit-значение (`{}`). Если возвращаемый тип функции _не_ `Unit` и тело функции завершает выполнение, то поведение не определено.

## Типы данных

### I32

`I32` &mdash; это тип, представляющий целое знаковое число.

|                         |                                                          |
| ----------------------- | -------------------------------------------------------- |
| Минимальное значение    | `-2 147 483 648`                                         |
| Максимальное значение   | `2 147 483 647`                                          |
| Размер                  | `4 байта (32 бита)`                                      |
| Поддерживаемые операции | `+`, `-`, `*`, `/`, `%`, операторы равенства и отношения |

### U8

`U8` &mdash; это тип, представляющий целое беззнаковое число.

|                         |                                                          |
| ----------------------- | -------------------------------------------------------- |
| Минимальное значение    | `0`                                                      |
| Максимальное значение   | `255`                                                    |
| Размер                  | `1 байт (8 бит)`                                         |
| Поддерживаемые операции | `+`, `-`, `*`, `/`, `%`, операторы равенства и отношения |

### Bool

`Bool` &mdash; это булев тип, имеющий два возможных значения: `true` и `false`. Он занимает 1 байт.

### Unit

`Unit` &mdash; это тип, имеющий нулевой размер. Его единственное значение &mdash; это unit-значение `{}`.

### Указатели

`T*` &mdash; это (non-const) указатель на тип `T`. `T const*` &mdash; это const указатель на тип `T`.

Например, `U8* const*` &mdash; это const указатель на non-const указатель на `U8`.

#### Получение указателя на значение

Чтобы получить указатель на значение, нужно использовать оператор взятия адреса `&` на lvalue значении.

```c3
fn I32 main() {
    I32 foo = 42;
    I32* ptr = &foo;
    return 0;
}
```

#### Чтение и изменение значения по указателю

Значение по произвольному указателю можно читать, используя оператор разыменования указателя `*`. Значение по non-const указателю можно изменять, используя оператор разыменования указателя `*`.

Если программа изменяет значение по const указателю, то она некорректна.

```c3
fn I32 main() {
    I32 var = 0;
    I32* ptr = &var;

    *ptr += 1;

    return *ptr; /* returns 1 */
}

```

#### Преобразования указателей

Допускается (явное) преобразование произвольного указателя на тип `T` в произвольный указатель на тип `U` для любых типов `T` и `U`.

> [!NOTE]
> Формальное описание семантики указателей слишком сложно для данной учебной спецификации. В C' при работе с указателями нужно придерживаться правил, подобных strict aliasing из C. Для уточнения семантики следует обратится к документации и исходному коду конкретного компилятора C'.

### Срезы

`T[]` &mdash; это срез на массив элементов типа `T`.
