## Программа на языке C'

Каждый файл `.cpr` образует _единицу трансляции_. Каждая единица трансляции образует _программу_. В случае успешной компиляции программы образуется один исполняемый файл.

### Выполнение программы

Эта спецификация определяет правила, по которым можно выполнить программу на языке C' шаг за шагом. Получившиеся после компиляции исполняемые файлы не обязаны в точности повторять эти шаги. Разве, получившиеся после компиляции исполняемые файлы должны воспроизводить _наблюдаемое поведение_, которое получается при выполнении программы шаг за шагом по правилам, описанным здесь.

Наблюдаемое поведение двух выполнений считается одинаковым, если для любого ввода:

1. Нижеперечисленные операции выполняются в одинаковом порядке и с одинаковым результатом:
   1. Чтение из стандартного потока ввода.
   2. Вывод в стандартный поток вывода.
2. Exit-code в выполнениях одинаковый.

Эта спецификация _никак не ограничивает_ выполнение, если в нём есть неопределённое поведение.

### Точка входа

Выполнение программы начинается с выполнения функции `main()`. Выполнение заканчивается при выходе из функции `main()`.

Например, данная программа выводит в stdout строку `Hello, world!` и завершается с кодом `0`.

```c3
fn I32 main() {
    println("Hello, world!");
    return 0;
}
```

## Функции

Каждая единица трансляции состоит из нескольких функций. Имена всех функций различны. Перегрузка функции по аргументам не допускается.

В каждой единице трансляции присутствуют [встроенные функции](#встроенные-функции). Имена этих функций не должны пересекаться с именами остальных функций, иначе программа некорректна.

В каждой единице трансляции должна быть функция `main()`, иначе программа некорректна.

### Объявление функции

```c3
fn RetType function(P1 param_1, P2 param_2, ..., Pn param_n) { ... }
```

Чтобы объявить функцию, нужно указать:

- Имя функции
- Возвращаемый тип
- Параметры функции
- Тело функции

Имена параметров функции должны быть различны, иначе программа некорректна.

### Возвращаемое значение функции

Выполнение функции завершается, если:

1. Выполнение тела функции завершается
2. Выполняется инструкция [return](#инструкция-return)

Если выполняется инструкция `return`, то возвращаемым значением функции считается возвращаемое значение `return`.

Если возвращаемый тип функции `Unit` и тело функции завершает выполнение, то возвращаемым значением функции считается unit-значение (`{}`). Если возвращаемый тип функции _не_ `Unit` и тело функции завершает выполнение, то поведение не определено.

## Типы данных

### I32

`I32` &mdash; это тип, представляющий целое знаковое число.

|                       |                     |
| --------------------- | ------------------- |
| Минимальное значение  | `-2 147 483 648`    |
| Максимальное значение | `2 147 483 647`     |
| Размер                | `4 байта (32 бита)` |

Поддерживаются бинарные операции `+`, `-`, `*`, `/`, `%`, унарная операция `-`, операции сравнения и отношения.

### U8

`U8` &mdash; это тип, представляющий целое беззнаковое число.

|                       |                  |
| --------------------- | ---------------- |
| Минимальное значение  | `0`              |
| Максимальное значение | `255`            |
| Размер                | `1 байт (8 бит)` |

Поддерживаются бинарные операции `+`, `-`, `*`, `/`, `%`, унарная операция `-`, операции сравнения и отношения.

### Bool

`Bool` &mdash; это булев тип, имеющий два возможных значения: `true` и `false`. Он занимает 1 байт.

Над типом `Bool` определены следующие бинарные логические операции: `||` и `&&`.

Бинарные операции `||` и `&&` вычисляются по короткой схеме. Сначала вычисляется левый операнд. Если значение левого операнда определяет результат всего выражение, то правый операнд не вычисляется.

Над типом `Bool` также определена унарная логическая операция `!`.

### Unit

`Unit` &mdash; это тип, имеющий нулевой размер. Его единственное значение &mdash; это unit-значение `{}`.

### Указатели

`T*` &mdash; это (non-const) указатель на тип `T`. `T const*` &mdash; это const указатель на тип `T`.

Вложенные друг в друга указатели допускаются.

Например, `U8* const*` &mdash; это const указатель на non-const указатель на `U8`.

Чтобы получить указатель на значение, нужно использовать оператор взятия адреса `&` на lvalue значении.

```c3
fn I32 main() {
    I32 foo = 42;
    I32* ptr = &foo;
    return 0;
}
```

Значение по произвольному указателю можно читать, используя оператор разыменования указателя `*`. Значение по non-const указателю можно изменять, используя оператор разыменования указателя `*`.

```c3
fn I32 main() {
    I32 var = 0;
    I32* ptr = &var;

    *ptr += 1;

    return *ptr; /* returns 1 */
}
```

Если программа изменяет значение по const указателю, то она некорректна.

Арифметика указателей не допускается.

Размер и выравнивание указателя определяется реализацией.

#### Нулевой указатель

Произвольный указатель может быть равен `null`. В таком случае он называется _нулевым указателем_.

Если происходит разыменование нулевого указателя, то поведение не определено.

#### Преобразования указателей

Допускается (явное) преобразование произвольного указателя на тип `T` в произвольный указатель на тип `U` для любых типов `T` и `U`.

> [!NOTE]
> Формальное описание семантики указателей слишком сложно для данной учебной спецификации. В C' при работе с указателями нужно придерживаться правил, подобных strict aliasing из C. Для уточнения семантики следует обратится к документации и исходному коду конкретного компилятора C'.

### Срезы

`T[]` &mdash; это (non-const) срез на массив элементов типа `T`. `T const[]` &mdash; это const срез на массив элементов типа `T`. Произвольный срез имеет _адрес_ и _длину_.

Вложенные друг в друга срезы допускаются.

Получить доступ к элементам среза можно, используя оператор индексации `[idx]`. Получить длину среза можно, используя оператор `len()`.

```c3
fn Unit f(I32[] a) {
    println("len=", len(a));
    println(a[0], " ", a[1]);
    ++a[0];
}
```

Если программа изменяет значения const среза, то программа некорректна.

При индексации среза `s` по индексу `i >= len(s)` поведение не определено.

Размер и выравнивание среза определяется реализацией.

#### Преобразования срезов

Non-const срез типа `T` можно (явно) преобразовать к произвольному указателю типа `T`. Const срез типа `T` можно (явно) преобразовать к const указателю типа `T`. В результате данного преобразования получается указатель, адрес которого является адресом преобразуемого среза.

К произвольному указателю типа `T` можно применить оператор среза `[from:to]`, чтобы получить из него срез типа `T` и такой же константности. Адрес такого среза &mdash; это адрес `p + from`, где `p` &mdash; это адрес указателя, а длина равна `to - from`. Если `from > to`, то поведение не определено.

При использовании оператора среза на указателе не допускается отбрасывать операнды `from` и `to`.

### Массивы

`T[n]` &mdash; это массив типа `T` из `n >= 0` элементов. Размер массива равен `sizeof T * n`. Если `n` равно нулю, то и размер массива равен нулю.

Чтобы получить размер массива `a`, нужно использовать оператор `len()`.

Чтобы получить доступ к элементам массива `a`, нужно использовать оператор индексирования `[idx]`. Когда индекс выходит за границы массива, программа некорректна, если индекс &mdash; это целочисленный литерал. Если же индекс является иным выражением, поведение не определено.

Используя оператор среза `[from:to]`, можно получить срез на часть массива.

### Сравнение значений

Два значения одинакового типа можно сравнить, используя операторы равенства `==` и неравенства `!=`.

## Выражения

### Свойства выражений

У выражения есть тип `T` и категория (lvalue или rvalue).

### Литералы

| Тип              | Литерал          |
| ---------------- | ---------------- |
| `I32`            | `123`            |
| `U8`             | `'x'`            |
| `Bool`           | `true`, `false`  |
| `Unit`           | `{}`             |
| `U8 const[]`     | `"foo"`          |
| `T*`, `T const*` | `null`           |
| `T[n]`           | `[ t1, t2, t3 ]` |

Все значения литералов относятся к категории rvalue.

### Бинарные операции

Группировка операндов бинарных операций определяется грамматикой.

К _бинарным операциям_ относятся сложение `+`, вычитание `-`, умножение `*`, деление `/`, получение остатка от деления `%`, сравнения `==` и `!=`, отношения `>`, `<`, `>=`, `<=`, логические операции ИЛИ `||` и И `&&`.

Получающиеся значения бинарных операций считаются rvalue.

### Унарные операции

Унарными операциями подразделяются на префиксные операции и постфиксные.

К префиксным унарным операциям относятся: оператор взятия адреса `&`, оператор разыменования указателя `*`, оператор унарный минус `-`, оператор логического НЕ `!`, операторы префиксного инкремента и декремента `++` и `--`, оператор преобразования типа `(T)`.

К постфиксным унарным операциям относятся: оператор индексирования `[idx]`, оператор среза `[from:to]`.

| Категория операнда | Операция          | Категория результата |
| ------------------ | ----------------- | -------------------- |
| lvalue             | `&`               | rvalue               |
| Любая              | `*`               | lvalue               |
| Любая              | Унарный `-`       | rvalue               |
| Любая              | Логическое НЕ `!` | rvalue               |
| lvalue             | `++`, `--`        | rvalue               |
| Любая              | `(T)`             | rvalue               |
| Любая              | `[idx]`           | lvalue               |
| Любая              | `[from:to]`       | rvalue               |

Значение вызова функции `f(a1, a2, ..., an)` относится к rvalue.

### Оператор присваивания

Значение оператора присваивания относится к rvalue.

### Порядок выполнения

Допускается любой порядок выполнения выражения, который удовлетворяет частичному порядку, образованному от синтаксического дерева выражения.

Например, программа ниже

```c3
fn I32 main() {
    f() + g();
    return 0;
}

fn I32 f() {
    print("X");
    return 1;
}

fn I32 g() {
    print("Y");
    return 0;
}
```

может вывести как `XY`, так и `YX`.

## Инструкции

### Блок инструкций

Каждая инструкция в блоке инструкций выполняется последовательно, сверху вниз.

#### Область действия переменных

Каждый блок кода создаёт одну область действия переменных.

Параметры функции являются переменными, объявленными в блоке тела функции.

У области действия может быть родительская область действия, которая принадлежит родительскому блоку кода. У блока тела функции нет родительской области действия.

Внутри отдельной области действия имена переменных различны. Переменные области действия могут перекрывать переменные родительской области действия.

Переменные недоступны для использования до своего объявления.

### Инструкция-выражение

При выполнении инструкции-выражения выполняется само выражение.

### Объявление переменной

Инструкция объявления переменной позволяет объявить несколько переменных одного типа.

Если в одной инструкции переменных объявляется несколько, то такая инструкция эквивалента нескольким инструкциям, объявляющим каждую из этих переменных отдельно и идущим в том же порядке объявления, что и в изначальной инструкции.

В частности, данная программа корректна и не содержит неопределённого поведения.

```c3
fn I32 main() {
    I32 a = 42, b = a;
    println(b); /* 42 */
    return 0;
}
```

Каждая такая переменная может быть или инициализирована, или не инициализирована. Если переменная не инициализирована, то и память под хранящееся значение не инициализирована.

### Условие if

Условная конструкция if состоит из нескольких основных ветвей и необязательной альтернативной ветви. Каждая ветвь имеет свой блок инструкций. Все основные ветви имеют условие.

Условие &mdash; это выражение, имеющее тип `Bool`.

Инструкция if выполняется следующим образом:

1. Текущей ветвью устанавливается первая ветвь инструкции if.
2. Вычисляется условие текущей ветви.
3. Если условие истинно, то блок, связанный с ветвью, выполняется и инструкция if завершает выполнение.
4. В противном случае текущей ветвью считается следующая основная ветвь, если она существует, и алгоритм снова переходит на шаг 2. Иначе инструкция завершается, предварительно выполнив блок альтернативной ветви, если она существует.

### Цикл while

Цикл while состоит из условия и тела.

Условия &mdash; это выражение, имеющее тип `Bool`.

Цикл while выполняется следующим образом:

1. Вычисляется условие.
2. Если условие ложно, то выполнение цикла while заканчивается.
3. Выполняется тело цикла и алгоритм возвращается на шаг 1.

### Бесконечные циклы

Бесконечный цикл называется _тривиальным_, если он имеет одну из следующих форм.

```c3
while (true) { ... }
```

или

```c3
for (;;) { ... }
```

Тривиальные бесконечные циклы бессрочно блокируют выполнение программы.

Если выполнение доходит до нетривиальные бесконечного цикла, никогда не влияющего на наблюдаемое поведение во время выполнения, то поведение не определено.

### Инструкция return

Инструкция return устанавливает возвращаемое значение и завершает выполнение функции.

Выражение return может быть любой категории.

Если тип возвращаемого выражения отличается от возвращаемого типа функции, то программа некорректна.

## Встроенные функции

### Стандартный ввод/вывод

#### Вывод

Функция `print()` принимает произвольное количество аргументов различного типа и возвращает `Unit`. При вызове `print()` форматирует аргументы и выводит каждый из них в стандартный поток вывода в порядке передачи функцию. Поддерживаемые типы аргументов указаны в таблице ниже.

| Тип аргумента | Пример форматирования |
| ------------- | --------------------- |
| `I32`         | 42                    |
| `U8`          | f                     |
| `U8 const[]`  | Hello                 |
| `U8[]`        | World                 |
| `Bool`        | true                  |
| `T*`          | 0x01                  |

Функция `println()` работает аналогично `print()`, но в конце добавляет символ конца строки.

#### Ввод

Функция `read()` принимает один non-const указатель на произвольный тип `T` и возвращает `Bool`. Если `T = I32`, то функция читает следующее десятичное число из стандартного потока ввода (ведущие нули игнорируются). Если `T = U8`, то функция читает следующий символ из стандартного потока ввода. Во всех случаях если не удаётся считать аргумент, то функция возвращает `false`. Иначе, функция возвращает `true`.

Функция `readln()` имеет следующую сигнатуру:

```c3
fn Bool readln(U8[]* value) { ... }
```

При вызове функция `readln()` читает строку из стандартного потока ввода, автоматически выделяя для неё динамическую память. Чтобы избежать утечек памяти, выделенную память нужно освободить с помощью `free()`. Если строку считать не удалось, то функция `readln()` возвращает `false`. Иначе `true`.
