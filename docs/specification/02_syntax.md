# Синтаксис языка C'

Синтаксис языка C' относится к C-подобным языкам &mdash; присутствует разделение на инструкции и выражения, скобки `{}` используются для блоков кода и инициализации, а `()` для выражений и вызова функций. В грамматике устранены некоторые неоднозначности.

## Приоритеты операторов

| Приоритет | Операторы                                         | Ассоциативность |
| :-------: | :------------------------------------------------ | :-------------- |
|   **1**   | `[]`<br>`[:]`<br>`()`                             | Слева направо   |
|   **2**   | `&`<br>`*`<br>`-`<br>`!`<br>`++`<br>`--`<br>`(T)` | Справа налево   |
|   **3**   | `*`, `/`, `%`                                     | Слева направо   |
|   **4**   | `+`, `-`                                          | Слева направо   |
|   **5**   | `==`, `!=`, `>=`, `<=`, `>`, `<`                  | Слева направо   |
|   **6**   | `&&`                                              | Слева направо   |
|   **7**   | `\|\|`                                            | Слева направо   |
|   **8**   | `=`                                               | Справа налево   |

## Разрешение неоднозначностей в грамматике

#### Объявление переменной vs выражения

Если в начале инструкции находится тип, то такая инструкция считается объявлением переменной. Иначе она считается выражением.

#### Группировка выражений vs преобразования типа

В операторе приведения типа внутри скобок обязательно должен находится тип данных. В группировке выражений типы данных не допускаются.
